# Code and research-data permissions

Original project code and documentation are offered under Apache-2.0; see LICENSE.
Third-party software retains its own license and notices.

The code license does not grant rights to redistribute downloaded filings,
articles, images, market data, broker observations, private office documents or
other third-party source material. Those items retain their original terms.
A file being present in a research tree is not evidence of redistribution rights.

Public research releases must retain their source and permission manifests.
Publish only original research or evidence for which an explicit eligible reuse
basis has been recorded. Private office data is excluded from application builds
and public research releases. Optional datasets require their own version,
checksums, provenance and source-specific permission metadata.
