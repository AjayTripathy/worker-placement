Retained cash reaches holders via **buybacks, which pay 1:1** — and Greif's completed $150M program bought **1.8M Class A vs 0.4M Class B**, with new repurchases announced for restart. That is the only convergence mechanism in existence here, and it points at A.

**Ruling on the pair.** Long A / short B is refuted, not sized down: (a) there is **no conversion right, sunset, or forced-collapse provision** — nothing enforces convergence; (b) carry is negative before borrow (short B costs 3.46%, long A earns 2.95%), on a class that is ~45% insider/family-held; (c) the "mean" being reverted to is a regime that the deleveraging destroyed. Liquidity is fine on both legs outright (A ~$21M/day, B ~$8.8M/day, 20d ADV), so an *outright* Class A position is executable — the short leg is the problem, and B borrow is **unverified** (IBKR MCP was permission-denied this session).
