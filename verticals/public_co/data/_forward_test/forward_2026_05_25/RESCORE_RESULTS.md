## Methodological lessons

1. **Form-4-only signals carry meaningful misclassification risk.** 3 of 7 (43%) had their classification meaningfully changed when broader m-sources were probed.

2. **The biggest re-score "wins" came from m-sources the original prompt didn't emphasize:**
   - Counterparty mirror via edgar_fts (Workday → NSP, MBC → AMWD, TPG/GUESS/B.Riley → XRX, Martin Marietta data-center → ASTE)
   - openFDA (PBH recall density)
   - BDC private-credit pricing via edgar_fts (PBH refinancing math)
   - usaspending (ALG federal-customer revelation)
   - uspto_odp (XRX patent-app collapse)

3. **Form 4 tax-withholding can be mechanically mis-classified as discretionary selling** if the agent doesn't distinguish F-code from S-code carefully. ASTE is the case study.

4. **For ANY future framework run, the prompt should require checking at least 3 distinct external m-sources per name**, not emphasize one. The form4 emphasis was well-intentioned but suppressed signal diversification.
